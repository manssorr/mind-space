## Why this matters

This repo has zero tests, no typecheck script, and no CI. The 748-line Zustand store (`src/store/index.ts`) holds all app state, undo/redo, and localStorage persistence, and three later plans (003, 004, 005) modify it. Without characterization tests, those changes cannot be verified. This plan creates the one-command "does the codebase work?" gate that every other plan uses.

### Step 2: Add Vitest

`npm install --save-dev vitest jsdom`

Create `vitest.config.ts` at repo root:

```ts
import { defineConfig } from "vitest/config"

export default defineConfig({

  resolve: {
    alias: {
      "@": path.resolve(__dirname, "src"),
    },
  },
})
```

Add scripts to `package.json`:


### Step 4: Write `src/store/index.test.ts` - characterization tests

Import `{ useStore }` from `@/store`. Reset state in `beforeEach` with a known fixture:

```ts
import { beforeEach, describe, expect, it } from "vitest"
import { useStore } from "@/store"
import { WidgetType, type Widget } from "@/types"

function makeWidget(id: string, overrides: Partial<Widget> = {}): Widget {
  return {
    id, type: WidgetType.Note, title: "w", x: 0, y: 0,
    width: 100, height: 100, zIndex: 1, collapsed: false, data: {},
    ...overrides,
  }
}

beforeEach(() => {
  localStorage.clear()
  useStore.setState({
    sheets: [{ id: "s1", title: "Sheet 1", widgetOrder: ["w1"], createdAt: 0, updatedAt: 0 }],
    currentSheetId: "s1",
    widgets: { w1: makeWidget("w1") },
    selectedWidgetIds: [],
    undoStack: [],
    redoStack: [],
    clipboard: null,
  })
})
```

Test cases (one `it` each; call actions and read results via `useStore.getState()`):

1. `addSheet` appends a sheet and pushes one undo snapshot.
2. `deleteSheet` removes the sheet AND its widgets from `widgets`, and moves `currentSheetId` to the first remaining sheet (or null).
3. `duplicateSheet` creates new widget IDs (no ID shared with the original) and appends `" (copy)"` to titles.
4. `updateWidget` merges partial updates and pushes an undo snapshot; unknown id is a no-op.
5. `moveWidget` changes x/y and does NOT push an undo snapshot (`undoStack.length` unchanged). This is current intended behavior.
6. `resizeWidget` changes width/height and does NOT push an undo snapshot.
7. `undo` after `updateWidget` restores the previous widget state and moves one entry to `redoStack`; `redo` re-applies it.
8. Any snapshotting action clears `redoStack`.
9. History cap: run `updateWidget` 55 times; `undoStack.length` is 50.
10. `copyWidgets` then `pasteWidgets` creates widgets with new IDs, offset positions, and sets `selectedWidgetIds` to the new IDs.
11. `deleteWidgets` removes from `widgets`, `widgetOrder`, and `selectedWidgetIds`.

**Verify**: `npx vitest run src/store/index.test.ts` -> 11 tests pass.
